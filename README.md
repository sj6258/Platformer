# Platformer
Moondew--Mountains
### INTRODUCTION :
I made a platformer game where you have to escape from cultists and reach the end

the game was made so that it would get harder as you progress

### TECH STACK :
i used godot and gdscript to make this project.

### WHAT I LEARNED :
I learned how to make the parallax background by layering images and changing the scrolling speed of each, I also learned how to make enemies and use raycasts, I also learned how to code double jump

### FAILURES :
the most difficult part was creating the level design of the game so it would fit perfectly with the speed and jump of the player, i also found it really hard to code the parallax effect which i think is one of the best featues of the game, coding double jump was also hard as it kept having bugs and wouldn't jump sometimes.

### CONTROLS :
WASD/ arrow keys to move space bar or up arrow or W to jump. The goal is to reach the end of the level
